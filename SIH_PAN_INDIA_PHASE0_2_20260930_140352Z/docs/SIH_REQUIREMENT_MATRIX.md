Status values used below, applied strictly (code merely existing is never enough for IMPLEMENTED):

- **IMPLEMENTED** — working, tested, real data, in production
- **PARTIALLY IMPLEMENTED** — real and working for a subset (e.g. VOBL only) but not the full stated scope
- **SOFTWARE VALIDATED** — code/architecture is real and tested but not running on production data at the required scale
- **ARCHITECTURAL ONLY** — designed/scaffolded, not executing on real data
- **DATA BLOCKED** — genuinely blocked on external data/credentials, not an implementation gap
- **NOT IMPLEMENTED**
