# Dashboard value provenance

Every value in the DRIFT command centre (`/drift`), with its source and how it is labelled. All fields come from `data/india_fields_latest.json` (GFS 0.25 degrees, one value per land cell and forecast hour) unless stated. Times shown per forecast hour: model init, valid time, S3 publication time of the NWP file (observed), acquisition time. **Status** (CURRENT / PAST_VALID_TIME / STALE / INVALID_PROVENANCE) is recomputed from those times and the clock in the browser/server; the producer's label is never trusted.

| Displayed value | Source | Location | Class | Unavailable behaviour |
|---|---|---|---|---|
| CAPE, CIN, lifted index, PWAT, T2m, dew point, RH2m, MSLP, 10 m wind, vertical velocity, soil water, APCP | NOAA GFS 0.25 degrees, AWS mirror, decoded with eccodes, header-checked | the 0.25 degree cell whose centre is one GFS grid point (exact extraction) | NWP input (raw model output) | `null`, shown as unavailable, never zero |
| K-index, Total Totals, lapse rate 850-500, bulk shear 850-500 hPa, convergence, PWAT gradient, specific humidity | computed from the GFS fields above (`pipelines/ingestion/gfs_reader.py`) | same cell | derived (shear is 850-500 hPa, not 0-6 km) | `null` if any input is missing |
| Forecast-hour chips (f3..f24), valid times, IST conversion | cycle init + forecast hour, recomputed | national | derived | stale/past hours labelled, never shown as current |
| LIVE FRESH / STALE badge, "Data: FRESH" | cycle age vs server clock (18 h limit) | national | derived | withheld when stale |
| Thunderstorm probability +6/12/18/24 h | `data/india_ts_model_latest.json`: XGBoost + isotonic, trained on METAR TS/VCTS labels (113 stations, Apr-Jun 2024/25) | cell | calibrated probability of **ordinary** thunderstorm, not severe | UNAVAILABLE if model not evaluated or leads fail the gate |
| Thunderstorm drivers (top 3) | TreeSHAP on the same model | cell | model attribution, not causal | UNAVAILABLE |
| Short-duration heavy rain, 20 mm / 3 h at f09 | `data/india_rain_model_latest.json`: XGBoost + isotonic, CMORPH labels | cell | calibrated probability, single target | other targets/hours UNAVAILABLE (failed the gate) |
| Heavy-rain-day outlook (1 degree) | `data/pan_india_grid.json`, model `panindia_cb_v1`, label IMD >= 64.5 mm / 24 h | 1 degree cell containing the point | **uncalibrated ranking score**, not a probability and not a cloudburst | labelled uncalibrated |
| Cloudburst | none | - | UNAVAILABLE (no sub-hourly labels or observations) | always UNAVAILABLE |
| Flash-flood prediction | none | - | UNAVAILABLE (no event labels, river or soil observations) | always UNAVAILABLE |
| Flash-flood screening index | heuristic from rainfall, terrain, soil water | cell | **heuristic, unvalidated, not a probability** | labelled |
| Elevation, slope, gauge distance | SRTM-derived terrain (~1.2 km), INDOFLOODS gauges (`data/india_static_025.json`) | cell | static derived | unavailable where missing |
| State / district | datameet states, geoBoundaries ADM2, by cell centre | cell | reference | - |
| Place search | GeoNames (3,756 places) | place | reference | exact matches rank first |
| Evaluation tab (AUROC, Brier skill, CIs, per-lead) | `data/*_evaluation.json` generated by training scripts | national / station set | evaluation | shown only for published targets |
| Operational lead time | not recorded | - | `null`: DRIFT publication time is not recorded | "LEAD-SPECIFIC 2-6 h WARNING UNAVAILABLE" |
| Alerts tab | `backend/alert_policy.py`, empty registries | - | fail-closed | all outputs not eligible |
| SIMULATION mode | `drift_sim.js`, synthetic scenario, no network | synthetic | **simulation**, labelled, isolated | cannot reach alert code |
| Legacy station dashboard (`/`) | `forecast.json`, `data/drift_live.json`, `skill_scores.json` for Bengaluru VOBL only | one airport | station model | tiles without a verified live source show a dash (hard-coded fallbacks removed in this change); banner states it is not national |

Legacy station dashboard: every typed metric, fake feed and unverifiable claim was removed or replaced by data; the dispositions are in `docs/evaluation/LEGACY_DASHBOARD_AUDIT.md` and are enforced by `tests/test_frontend_claims.py`.
